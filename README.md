# cardputer-fw

Прошивки для **M5Stack Cardputer ADV** (ESP32-S3FN8, 8 MB flash) и манифест для обновления по воздуху.

## Что здесь

| Файл | Назначение |
|---|---|
| `manifest.json` | что заливать на устройство: версия, ссылка, sha256, размер |
| `catalog.json` | список прошивок, которые вообще можно поставить (свои сборки + сторонние) |
| `tools/flash_ota.py` | заливка по сети через WebUI лаунчера (без USB) |
| `tools/build.ps1` | сборка кастомного лаунчера (PlatformIO) |

## Как устроено обновление

Устройство работает под кастомным Launcher (форк [bmorcelli/Launcher](https://github.com/bmorcelli/Launcher), тег 2.9.1) со своей разметкой flash:

```
0x0009000  nvs        20 KB
0x000e000  otadata     8 KB
0x0010000  app0        2 MB    <- лаунчер + агент
0x0210000  coredump   64 KB
0x0220000  ...         ~5.5 MB под приложения (создаются лаунчером)
```

Обновление — по запросу: бинарь публикуется в Releases, `manifest.json` указывает на него.
Устройство либо заливается push-ом из `tools/flash_ota.py`, либо (позже) само тянет манифест.

## Releases

Каждый релиз = один merged-образ (bootloader + таблица разделов + app), как в апстриме.
`flash_ota.py` и `installExtFirmware()` лаунчера понимают именно такой формат.

## Безопасность

- WebUI лаунчера закрыт логином (`wui_usr` / `wui_pwd`), cookie `ESP32SESSION`.
- Бинарь проверяется по `sha256` из манифеста.
- Wi-Fi пароли в лаунчере хранятся в `config.conf` на SD **открытым текстом** — карту не терять.
